Personal Portfolio Website

A personal portfolio website designed to showcase my skills, projects, and journey as a Frontend Developer. Built with a focus on modern UI design, responsive layouts, smooth interactions, accessibility, and a clean user experience.

🚀 Overview

This portfolio represents my journey into software development, my passion for building interactive web experiences, and my commitment to continuously improving my skills as a developer.

It serves as a space to showcase my projects, technologies I work with, and ways to connect with me.

- Responsive design across mobile, tablet, and desktop devices
- Modern and minimal user interface
- Smooth scrolling and interactive animations
- Project showcase section
- Skills and technologies section
- Contact section with social links
- Interactive navigation

2. Navigate into the project folder:

   cd YOUR-REPOSITORY

3. Open "index.html" in your browser, or use the VS Code Live Server extension.
